## Why

Measured on the owner's machine (2026-11-01 21:40, reported on the bus by another lane): 18 live Claude Code sessions ×
the plugin's four MCP servers = 72 node proxies (`aiplus-office.mjs <app> mcp`), about 1.1 GB together, plus 72
`*craft-cli mcp` processes (~130 MB). The four servers had to be denied in `deniedMcpServers` (144 processes → 0,
~1.2 GB freed). Claude Code sessions almost never call these tools: the skills use the bash route
(`aiplus-office <app> exec`).

Measured here (2026-11-01, Node 25.6.1, Linux): a freshly started idle proxy holds 87 MB RSS; bare Node holds 50 MB; a
craft-cli server before its first call 4 to 8 MB. The cost is one node process per app per session.

## What Changes

- A new command `aiplus-office mcp [--root <dir>]`: one stdio MCP server for the four apps. It lists their tools with a
  prefix (`word_`, `grid_`, `deck_`, `pdf_`; the apps share names such as `list_commands`, `batch`, `select`,
  `insert_chart`) and routes each `tools/call` to that app.
- The client's `initialize` and `tools/list` are answered from a tool manifest bundled at build time
  (`src/mcp-manifest.ts`, generated by `scripts/mcp-manifest.mjs` from the real servers). An installed app's server
  starts only at its first `tools/call`; an app that is not installed starts downloading at once, as before. When an
  app's server runs, its own tool list replaces the manifest's and the client gets `notifications/tools/list_changed`
  if it differs.
- Inside, each app runs through the existing per-app proxy (`runMcp`): confinement, the GridCraft gateway, serialised
  calls and the lazy start are unchanged.
- `release/mcp.json` registers this one server (`aiplus-office`) instead of four. `aiplus-office <app> mcp` stays for
  standalone use and `--register`.
- Skills and docs name the one server. Version 0.1.23.

Not in this change: stopping an idle app server (it would drop the open document; the measured cost is the node
process, not the app), resources and prompts of the app servers (the combined server lists none).

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `office-mcp`: one server for the four apps; no app process before its first call.
- `plugin-packaging`: the plugin registers one MCP server.

## Impact

New `src/mcp-hub.ts`, `src/mcp-manifest.ts`, `scripts/mcp-manifest.mjs`, `src/bin/aiplus-office.ts` (the `mcp`
command), `release/mcp.json`, the bundle, tests, skills (router, the four app skills, start), README. A client that
denied the four old server names (`plugin:aiplus-office:aiplus-office-<app>`) gets the new one; the old deny entries
can go.
