### Requirement: Plain Chat said plainly

The plugin description, the public README and `office-start` SHALL say, Hungarian first, then English, that a plain Chat
in Claude Desktop handles all four file types in the „AI+ Iroda” folder of the user's Documents, and that a folder of the
user's choice needs Claude Code or a Claude Desktop session whose environment is „This computer”. No surface SHALL say
that a plain Chat handles Word and PDF only.
